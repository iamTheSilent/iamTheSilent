## What I'm building

### 🪺 Laneh: a day and team planner where AI is a real teammate
A Persian-first planner for individuals and small teams, on Windows, Android and the web. Version 1.2.3 is out. Built for teams in Iran, a market that global tools mostly ignore: Shamsi calendar, real right-to-left layout, and no dependence on sanctioned services.

- **Two spaces that never mix.** Your personal planner stays on your device. Team workspaces sync live (SSE) across members and devices.
- **Path to goal.** Each project is a chain of stages. The critical path is highlighted, and the finish date is forecast from the team's actual pace.
- **Claude as project manager.** An MCP server connects an AI assistant to your team with exactly your permissions. It has 25 tools, 3 ready workflows (weekly review, project design, load balancing) and 47 automated tests against the live server. AI-made changes are labelled, so every decision stays visible and reversible.
- **Ships often:** six releases since the first commit in June 2026, with in-app updates on Windows.

### 🏥 Clinic management system (private, client project)
Built from scratch for a private clinic and now launching. It has separate roles for reception, midwife and doctor, so each role sees only the data it needs. Every clinical read by someone outside the patient's care is logged. Backups are encrypted, and restoring them is tested on a schedule.

## How I work
- **Measure first.** Forecasts, retention curves, A/B decisions: if it can be counted, I count it before I argue about it.
- **Solve the real constraint.** Unreliable networks, right-to-left text, servers that can't reach the APIs they need. The constraint usually shapes the design.
- **Ship in small steps** and write down what each release proved and what it didn't.
- **Build with AI agents while owning the decisions.** Agents write a lot of my code. Tests, reviews and the final call stay with me.
